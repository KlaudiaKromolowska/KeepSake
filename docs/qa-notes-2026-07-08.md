# QA browser pass — 2026-07-08 (post-Phase-3 merge)

Visual/a11y review of the shipped kiosk on the local stack (Chrome, 1568×699 and 1920×855
viewports, DEMO_MODE, 60×). Functional behavior separately verified by the D3 gate. Items feed
the Phase-5 polish/a11y pass (5.2/5.3) unless marked earlier.

## Findings

1. **Theme jump: dashboard/login are dark, kiosk is light.** `globals.css` swaps to dark via
   `prefers-color-scheme`, but only the session screens force light. Moving demo flow
   dashboard→session flashes dark→light, and the dark palette was never contrast-designed
   (subtitle text on near-black card looks sub-7:1). *Recommendation:* force light app-wide
   for MVP (one-line change) — revisit dark mode post-hackathon. **Do in Phase 4 UI tasks if
   trivial, else 5.2.**
2. **Session footer below the fold at ≤~750px viewport heights.** End session / Answer card
   require scroll on short/landscape screens. *Recommendation:* sticky footer
   (`sticky bottom-0 bg-white`) or tighter vertical gaps on kiosk sections. **5.2.**
3. **Visible focus ring on the phase heading.** Programmatic focus on `<h1 tabIndex={-1}>`
   draws a default outline rectangle ("Time to ask" boxed). Harmless, slightly untidy on
   camera. *Recommendation:* `focus:outline-none` on the kiosk h1s (focus still lands for AT;
   ring adds nothing for a non-interactive element). **5.2 — decide with a11y hat on.**
4. **Missing-photo state is clean** (post-92a7843): no broken-image glyph, text-only layout
   balanced. ✔ no action.
5. **Adjust-wait rung picker**: 12 chips render in one row on desktop, wrap on tablet; current
   rung clearly outlined; labels carry contrast (borders are light but not the only signal).
   ✔ no action. The fast-ticking compressed clock reads as intended time-lapse on camera.
6. **Dashboard content**: sparse (one card + raw `signed in as demo@keepsake.test` line).
   Phase 4 adds wizard + review cards; the signed-in line wants friendlier copy in the 5.3
   wellness-copy pass. Cards' dark-mode contrast resolved by finding 1.
