# KeepSake — hackathon submission film (shot-by-shot script)

> **Format:** ~3:00 · "Built with Claude: Life Sciences" · Builder Track · aiming for 1st.
> **Arc (science-forward, per PLAN §1b v4.1):** hook → the human problem → the neuroscience →
> the LIVE session (never-cut chain) → the Claude magic (wizard self-critique shown on screen →
> agentic research view; coach + Haiku grader credited) → practitioner-validated + evidence-driven
> credibility → close on impact.
> **Framing = FOR JUDGES (PLAN §10 / §1b Reframe #2):** name dementia, cite the neuroscience,
> lead with impact + the clinical-data angle. This is a *research prototype*, so disease-naming is
> a strength. Avoid only unsubstantiated efficacy claims ("this treats/slows dementia").
>
> **VO:** written to be spoken (ElevenLabs) — warm, clear, unhurried. Total = **357 words** (fits
> ~3:00 at a calm ~135 wpm, with the self-critique beat now near-silent and the "let it breathe"
> pauses in the session beat).
> **Voices:** one warm narrator throughout; the practitioner line was recorded organisation-generic.
> (Naming consent landed 2026-07-12 — written materials name Monika Stroińska, Centrum Montessori Senior.)

## Director's notes

### What to actually capture on the real prod app (keepsake-nu.vercel.app)
Everything in the 1:10–2:40 block is **real screen-capture of the deployed prod build** (judges may click the same URL — the video build must match prod, PLAN §1b submission checklist). Capture, in order:

1. **Session never-cut chain (1:10–1:52)** — `/session` kiosk: pre-session → *(pre-affect tap or skip)* → probe (dual-coded photo) → **deliberate miss → tap "Not this time" → device correction screen** → distractor card with the **live interval clock** → return probe → **recall → memory-capsule reward** → end-on-win → *Session complete*. Record it as **one continuous take** — the "never-cut chain" is the trust signal; do not cross-dissolve through the correction.
2. **Wizard self-critique (1:52–2:12, the held hero shot)** — the target wizard turning a messy description into a target and **showing the rejected draft + reason** (`selfCritique.rejectedDraft`: "This combined two facts — splitting into two"). This is now a single continuous ~6–8s near-silent take — **no montage; hold on it and let the self-correction land.** Use the canned/fixture replay (`CLAUDE_FIXTURES=1`) so the beat lands every take — genuinely model-generated, pre-recorded.
3. **Coach + grader (lower-third credit only, no VO)** — the caregiver coach (`/coach`, "Talk it through") and the Haiku real-time grader are now credited in a brief lower-third under the self-critique shot, **not shown as separate insets**. Capture a short clip only if you want a faint background under the card; keep any caregiver typed line generic (no real PII).
4. **Agentic research view (2:12–2:40, the jaw-drop)** — `/review`: type the suggested question, let the report **stream**, then **expand "How this report was produced"** so the list of Claude-chosen analyses is on camera. This agency trail is the 25%-Claude-Use money shot — hold on it.
5. *(Optional insert if a take runs short)* — `/etiology` extended-thinking reasoning, or `/schedule` booster cadence, as a 10s cutaway after 1:52 (PLAN §1b: etiology depth lives in README/appendix, film only if time).

### Pre-shoot setup (do before rolling)
- **Re-seed pristine demo data:** run `scripts/seed.ts` (the rich ~14-day arc: acquisition → mastery on 3 distinct days → maintenance with a booster dip + recovery, affect rows). Every filmed surface (session, capsule, `/review`, `/schedule`) renders from this — charts must look *alive*. Re-seed immediately before the take so no prior click-through pollutes the logs.
- **DEMO_SPEED compression profile (NOT flat 60×):** run the **first 15s interval REAL** with the visible clock; accelerate or jump-cut only intervals **> 60s** (PLAN §1b demo-engineering rule — at flat 60× the distractor phase vanishes and the loop reads as fake). `DEMO_SPEED` scales only the wall-clock wait, never persisted data.
- **Fixtures for API-dependent beats:** `CLAUDE_FIXTURES=1` so wizard / coach / review replay real pre-recorded model outputs — no take depends on a live round-trip, and no live API credit is spent per take.
- **Force light theme** on filmed pages (`/review` already forces it per the 2026-07-08 QA note); verify session kiosk renders white-bg on the capture machine so an OS dark scheme never flips a shot mid-take.
- **TTS / VO:** narrate with the pre-generated ElevenLabs lines (never live browser Web Speech on the money shot). Audition the kiosk narration audio pack before locking.
- **Scratch take first (mandatory, PLAN §1b):** record the whole beat sheet rough, watch it, fix what reads badly (pacing, compression, the correction beat) — then shoot for real.
- **Disclaimer on screen at close:** *fictional persona · not a medical device* (submission-checklist requirement). Persona = consented/fictional "Marta & Lena", never real patient data.
